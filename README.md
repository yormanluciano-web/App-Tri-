# Cómplice — Conexión a tu ritmo

PWA de juegos privados para 2 o 3 adultos que comparten un teléfono. Cada sesión es diferente. Tus límites siempre cuentan.

- 9 juegos, 3 intensidades (Leve, Picante, Perverso) y 1.083 actividades revisadas.
- Límites individuales con semáforo, autorizaciones privadas y unánimes, equilibrio de protagonismo.
- Sin cuentas, sin analítica, sin IA online. Funciona sin conexión.

```bash
npm ci && npm run dev        # desarrollo
npm run build && npm run preview   # producción local en http://localhost:4173
```

Documentación: `CLAUDE.md` y `docs/` (estado, decisiones, pruebas, contenido, despliegue e instalación en iPhone).
